# 1.4.32 当前发布状态与历史失败显示修复

日期：2026-09-19。分支：`codex/publish-status-1.4.32`。

## 原因与修复

1.4.31 遇到图片银行容量不足会正确暂停批量任务，但保留了商品上一次失败回执。商品工作台和待上架列表仍读取该旧回执，导致最近任务提示空间不足，而商品行显示之前的“弹窗遮罩，上架失败”。

现在两个列表及状态筛选统一使用当前任务进度。当前商品显示“正在上架”“正在暂停”或“上架已暂停”及当前原因；后续商品显示“等待处理”。已经处理的商品使用实际结果。退出任务后恢复历史结果展示，不删除或改写历史回执，不修改成功/失败计数。

该逻辑直接兼容升级前保存的暂停任务，无需修改客户商品资料或重新发起任务。
