# 1.4.56 属性映射修复验证

日期：2026-10-04。

## 问题与修改

客户在保存草稿或发布商品时，来源商品已有 OE 代码，但目标发布页的 `OE代码` 输入框为空；商品规格也可能没有被选中。原因是不同语言、账号或类目页面会重新生成属性 ID，旧逻辑只按来源 ID 匹配，且来源字段名称不一定是 `OE代码`。

- 为 OE 代码补充 `OE Number`、`OE Code`、`OEM Number` 等明确别名。
- 仅允许 OE 代码在精确 ID 匹配失败后通过规范名称跨 ID 对齐，普通属性仍保留 ID 校验，避免误填同名字段。
- 读取目标发布页实际显示的销售属性标签，将 `Specification`、`规格`、`型号` 等映射到目标规格控件，再写入所有规格值。
- 增加跨语言、跨属性 ID 的回归夹具，覆盖保存草稿前的目标页面填充。

测试不使用客户账号、客户商品或真实发布页面。

真实商品仍需在 1.4.56 客户端中重新保存草稿并重试发布。若某个类目的目标页面使用了完全不同的字段名称，请保留商品链接、目标类目和发布页字段截图，以便继续补充受控映射。
