# 1.4.60 中国制造网采集验证

日期：2026-10-05 至 2026-10-06。

## 本次行为

- 新增中国制造网入口，支持英文商品详情页单件、多链接批量和供应商店铺/商品分组采集。店铺按指定页码翻页，限定商品数量，对商品编号去重；列表断点与已处理商品分别持久化，暂停、继续沿用原任务。
- 解析当前商品的标题、主图、详情、普通属性、价格区间/阶梯价、起订量和明确公开的包装数据。保存原始来源快照，图片缓存到本地后改写详情图片地址，避免页面防盗链影响工作台和发布上传。
- 不把样品价作为批量售价，不把产能作为库存，不根据普通属性的逗号文本编造 SKU 组合。未公开售价的询价商品保留空价格并提示补充。
- 对照内置国际站目录的描述性类目名称，仅自动采用唯一对应的末级类目。来源更细时可以采用有明确同名国际站末级类目的来源上级；同名多候选或无法明确对应时显示候选，不套用来源站编号。保留已选择或引用的目标类目。
- 引用窗口新增来源平台筛选。中国制造网商品可以引用从1688、国际站等平台采集后成功上架的商品；预览后保存目标类目、属性、规格，标题、售价、主图和详情保留本商品内容。
- 人工验证窗口支持中国制造网域名及其验证会话。修改安装包校验工具，使其核对加密构建输出；新增业务模块沿用现有发行包源码保护。

## 验证边界

发布填写测试使用本地 Chromium 表单核对已保存属性和包装字段；真实公开页面测试仅检查采集、编辑、引用、发布计划，没有向国际站创建或提交商品。国际站的账号权限、类目变更、必填属性和审核结果仍需实际卖家页面验证。已引用规格需要核对是否符合本商品，不能据此承诺所有品类均无错误。未公开的数据不会凭空补齐。

真实支持范围为供应商英文产品页及英文店铺/商品分组列表。验证码由用户完成；不执行来源页面返回的脚本挑战。站点拒绝访问或不公开的字段会记录为需处理信息。
