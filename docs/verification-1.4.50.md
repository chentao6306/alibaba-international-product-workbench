# 1.4.50 国际站类目目录

## 影响分析与最终改动

修改前检查了单品编辑表单、批量修改和预览、类目读取 API、发布路由、属性编号与来源快照、成功商品引用流程，以及安装包收集规则。

- 原下拉框只有 4 个带有效 ID 的固定类目。新增 `src/CategorySelect.jsx` 和样式，单品重选和批量类目使用同一选择器：逐级浏览、中英文显示、名称/祖先路径/ID 搜索、最近 20 次选择、保留同类商品链接读取。只允许确认末级类目，浏览和取消不保存商品；切换显示语言不改变类目 ID 或英文标准路径。
- `server/category-catalog-data.js` 是 2026-09-23 官方目录快照。`GET /api/categories/catalog` 从安装包读取，客户选择类目无需额外登录或访问国际站。共享模型按 ID 校验父子关系和末级标记，不用同名类目合并节点。
- `server/product-edit.js` 的共享处理在明确改变类目 ID 时清除旧类目和属性编号绑定，供前端、单品 API、批量 API 共用。保留属性文字、规格选项、SKU 编号/价格/库存、图片和来源快照；新类目的属性需重新核对。同类目编辑继续保留原编号。
- `server/category-routing.js` 接受官方短数字 ID：目录中有 110 个三位数末级 ID，旧的四位数下限会丢失它们。保留旧有带标签的长 ID 解析，商品名称中的“5G”不会被当成 ID。
- 版本号和 lockfile 更新至 1.4.50。无依赖变更。本轮没有改动授权服务、采集、规则确认、验证码窗口和发布提交流程；保留 1.4.49 已完成的修复。

## 官方目录取证与维护

正常登录后，在国际站类目页面读取官方页面脚本使用的 `/product/category/subCat.jsonp`，从 `catIds=0` 逐级遍历，分别读取 `en_US` 和 `zh_CN`，按 ID 和末级标志逐项核对。`postCat.jsonp` 只返回当前店铺经营范围，不能用它替代全站目录。

结果：50 个一级类目、8,524 个节点、7,521 个明确末级。末级路径深度为二级 100 个、三级 4,006 个、四级 3,415 个。手机 201896803、无人机配件 201346401、毛绒钥匙扣 201774004、其他农业产品 135 均在目录中。

以下 4 个目录在中英文单独重试后，官方仍成功返回空子目录：Plant Seeds & Bulbs（100001862）、Plant Oil（100009255）、Home Video & Accessories（201934601）、Interior Systems（202054017）。保留为不可确认的目录，展示提示；不猜测其下属 ID，不宣称这 4 个分支已完整覆盖。

维护工具 `tools/sync-category-catalog.mjs <本机已登录测试浏览器的 CDP 地址> [输出文件]` 仅允许连接本机 127.0.0.1。工具不登录、不提交商品；输出仅包含 ID、层级、中英文名称、末级标记和更新时间，不包含账号、cookie 或店铺权限。校验成功后才写出快照。目录更新需重新同步并发布安装包。

## 风险与审查

- 跨类目可用的属性不同。本次保留文字供用户校对，清除失效编号避免错绑，不能保证旧商品切换到任意类目后即可直接发布。
- 全站可浏览目录不等于店铺经营授权。能否发布仍由店铺经营类目和国际站规则决定；客户端没有改变平台限制。
- 最近使用只保存公开的类目 ID。目录请求在卸载时取消，同类商品读取在切换选择/输入/关闭时取消并忽略过期响应，避免异步结果覆盖新选择。搜索输入按回车不会提交整个商品表单。
- 只在明确改变类目 ID 时重置旧绑定。引用成功商品的既有原子预览/保存流程继续测试，未将参考商品的新绑定误清空。
- 本轮官方接口操作是只读目录同步；界面、单品和批量保存测试使用隔离工作区，不对真实店铺发布商品。

## 手动验证

1. 等运行中的任务结束，退出旧客户端，安装 1.4.50；原有商品无需删除或重新采集。
2. 编辑任意商品，点击“重选类目”。浏览一级和子类目，确认上级目录不能点击“确认选择”。例如 Food & Beverage → Fruit & Vegetable Products → Fruit Products → Dried Fruit 可选择四级末级（ID 229）。
3. 搜索“毛绒钥匙扣”、`Plush Keychains` 或 `201774004`，应找到相同类目。切换中英文后 ID 保持一致。
4. 浏览后取消，原类目应保持；确认选择只更新编辑窗口，点击窗口底部“保存”才持久化。保存后重新打开，检查类目和图片、价格、库存、SKU。
5. 勾选几件商品 → 批量修改 → 产品类目。确认末级后检查预览，再点击“应用到 N 件商品”。取消批量窗口则不保存。
6. 重开选择器，“最近使用”应显示已确认的末级；目录浏览在离线时仍可使用，读取同类商品链接需要网络。更换类目后核对新类目属性，先用“保存草稿”验证目标店铺权限及必填信息。
