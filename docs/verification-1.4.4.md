## 发布与安全边界

- 客户端使用服务器时间和单调计时授权，30 秒主动心跳，授权租约最长 70 秒。断网后的检测存在这个有限窗口；电脑日期回拨不会延长已签发租约。失败会停止本地授权任务。
- 关闭 packaged Node 调试、RunAsNode 和 NODE_OPTIONS；开启 ASAR 完整性校验与仅加载 ASAR。客户端 JavaScript 仍可被研究，压缩或图标更换不能隐藏框架或保证无法逆向。需要更强代码保密时，应将关键算法移至服务端。
- 目前授权服务器按授权账号和设备签发客户端会话，Alibaba 账号真实性由客户端检查。被修改的客户端仍可能绕过本机检查；服务端独立激活凭据或可信身份凭据尚未引入。这是待解决的架构边界，不能宣称已防破解。
- 安装包未使用商业代码签名证书。签名发布、更新来源验证、渗透测试及持续安全更新仍需落实。
- HTTPS IP 证书已申请，ACME 续期路径已配置。但公网 TCP 443 测试仍超时，需腾讯云安全组放行。当前保留 HTTP 地址兼容旧客户端，尚不能保证授权及后台流量的传输保密性。放行后先验证 HTTPS，再切换客户端及后台并逐步停用旧 HTTP 接口。
- 服务器还存在操作系统安全更新和运行时维护任务；本次未进行整机升级或重启，以免影响在线授权。部署脚本支持服务健康检查失败时回滚代码及 systemd 配置。
- 无真实 DeepSeek 密钥，未进行真实计费调用；已测试接口格式、异常处理、保存重启及模拟翻译响应。速卖通结构化数据和加工测试通过，尚缺用户指定链接的完整实采及上架验证。
