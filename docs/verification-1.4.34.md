# 1.4.34 上架使用已保存资料

日期：2026-09-19。分支：`codex/publish-saved-data-1.4.34`。

## 行为变更

- 删除上架前资料不全、发布后必填属性缺失、类目失效这三条自动访问来源商品页的路径。草稿、直接提交以及暂停后继续均使用工作台已保存的商品资料。原有手工编辑、主动重新采集和已指定成功商品引用入口继续可用。
- 上架仍会读取国际站发布表单，并按已保存的媒体地址下载及上传图片、视频；这些操作不重新采集来源商品详情。来源确实缺少的资料需由用户编辑或主动重新采集，不虚构属性，也不关闭平台验证检测。
- 详情编辑器切换改用 Locator 的正常点击，先居中滚动，再等待稳定和可点击，允许布局移动或节点重建。保留防止反复切换慢速编辑器的状态；按钮未就绪时保留任务进度，不将其算成商品资料失败。
- 属性菜单忽略 Escape、Tab 且字段标签不可点击时，增加对实际空白区域的命中检查后点击收起。真正模态框和未知提示不会通过此路径点击穿透。
- 未能关闭的遮罩记录其可见文字和类型，并在任务中显示提示内容，避免只有笼统的“有弹窗遮罩”。
