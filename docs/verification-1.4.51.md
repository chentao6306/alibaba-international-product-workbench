# 1.4.51 图片编辑与多套商品详情模板

日期：2026-09-28。保留此前版本的类目、授权与发布修复；本次无依赖升级。版本及 lockfile 同步为 1.4.51。

## 商品图片

- 入口：勾选商品 → 批量修改 → 产品图片。主图最多 6 张、详情图最多 30 张；支持本地 JPG/PNG/WebP 上传并追加或替换、单张删除、按序号批量删除、清空详情图。
- 软件文字水印支持文字、颜色、位置、大小、透明度和作用范围。修改水印使用原底图重新生成，不反复叠加；保存后重新打开仍可删除软件水印，恢复添加前底图。
- 原图自带水印使用框选区域修复，可处理单张或批量同位置区域。算法为边界颜色插值，适合简单背景，不是生成式 AI；复杂纹理、文字覆盖主体可能留下痕迹，需检查前后预览。单次选区限制为图片面积的 25%。
- 所有图片操作先进入编辑草稿，明确保存才更新商品；支持撤销和恢复本次编辑前状态。并发修改或运行中的发布任务会阻止过期保存。保留来源快照、规格、价格、库存。
- 上传图片解码验证、去除元数据并转存；远程图片下载检查 DNS、重定向、目标端口、私网地址、大小与超时。本地图片访问拒绝目录越界与符号链接，缺失图片提示重新上传。

## 多套详情模板

- 入口：勾选商品 → 批量修改 → 详情描述。客户可维护最多 50 套命名模板，新建、复制、修改、删除、持久保存；修改模板不会自动改动已经应用的商品。
- 共用富文本编辑器，支持粗体、斜体、列表、HTML 排版及本地公司图片。提供商品标题、品牌、型号、商品详情图变量；变量在每件商品的文字节点中展开，不插入 URL 或样式属性。
- 选择替换整个详情、前置或追加。必须保存模板并预览后才能批量应用，可逐件比较前后内容。模板和商品版本检查确保批量保存全有或全无。
- 重复应用会更新已有的模板区块，旧公司图片不会混入新的商品详情图变量。模板应用后可继续用图片编辑功能增删或处理图片。删除模板不会删除已应用详情；存储清理保护模板引用的本地图片。
- 自定义模板绕过仅针对采集详情的供应商介绍清洗，保留客户的公司文字、表格和图片位置；发布时将本地图片上传到国际站图片银行后映射回模板布局，不直接提交本机图片地址。缺图或编辑器不支持可靠上传时停止提交，避免错图、漏图。
- 模板允许纯文字详情，实际店铺发布结果仍由平台必填规则决定。含图片模板使用普通图文编辑器图片上传组件；真实店铺需先保存草稿确认模板排版。

## 使用顺序

1. 等当前任务结束，退出旧版本后升级；已有商品无需删除或重新采集。
2. 在产品图片页完成图片处理并保存。对原图水印修复先检查效果。
3. 在详情描述页新建模板，替换示例提示为客户自己的内容，插入所需商品变量，上传公司图片，保存模板。
4. 选择应用方式、点击预览，逐件确认商品标题、图片及公司内容，再确认应用。
5. 更换模板、编辑模板或增删图片后，可重新应用。首次使用先在国际站保存草稿检查最终效果，再批量发布。
