# 自定义属性长名称修复记录

日期：2026-11-09。基于 1.4.98 工作区的新源码补丁，纳入 1.4.99 候选版；不覆盖既有 1.4.98 安装包。

## 已确认问题

一份 1.4.88 诊断报告保留了 5 条失败：2 条自定义属性名称超长、1 条详情文本控件在滚动时脱离 DOM、1 条卖家页面或浏览器关闭、1 条目标类目未开通。它们不能归为同一个原因，也不能据此推算全部任务的失败分布。

名称为 `provide mould making and sample making service`，46 字符；当前自定义属性输入限制为 40 字符。来源值为 `sample making`。来源结构包含带属性 ID 和不带 ID 的两种保存形态。原商品类目和当次目标类目不同，目标表单没有该原生属性，转入自定义属性后触发长度拦截。

## 修改

`server/custom-attributes.js` 为这个明确的名称提供 `Mould making and sample making service`（38 字符）的等义发布名称。仅删除标签中的冗余动词，保留两种服务的含义及原始属性值。

- 原始商品、采集快照、来源名称、属性 ID 与用户编辑不变。写入回执分别保留 `name` 和 `postingName`。
- 有对应原生属性 ID 时仍走原生字段，不改为自定义字段。
- 等义名称对应不同值时，在任何写入之前停止并报告冲突。
- 仍读取实际 `maxlength`，写入后重新核对值；不会截断未知名称、单位或属性值。
- 未调整其它类目的别名字典、类目选择、发布权限或提交行为。
