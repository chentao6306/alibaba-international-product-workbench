日期：2026-09-29 至 2026-09-30。版本与 lockfile 同步为 1.4.52，无依赖升级。

## 已复现的问题与修复

使用构建后的前端、隔离商品库和内置 Chromium 验证了客户报告的输入问题。修复前，在类别要求新增的空白“应用领域”中连续输入 `Christmas decorations`，仅留下 `C`，输入框丢失焦点；非必填“使用说明”也仅留下第一个字符。已有的型号、类型和品牌名称输入正常。原因是缺失属性首次输入时从缺失字段列表移到已有属性列表，React 重建控件。

- 将已有属性与类目要求统一为稳定的编辑行；第一次填写不会切换列表或输入控件。
- 必填和选填字段都使用类目已知的下拉、多选定义；保留已有属性值和来源证据。
- 优先按属性 ID 匹配类目定义，再按名称匹配；不同 ID 的同名属性不会被合并。
- 保存沿用原有商品修改 API，编辑值发生变化时清除旧选项 ID。

## 编辑值在发布页生效

`tools/product-attributes-qa.mjs` 使用真实编辑 UI 保存并重新读取商品，再调用生产代码 `preparePublishProduct`、`createPublishSnapshot`、`fillCategoryAttributes` 和 `requireCategoryAttributes`，向隔离的发布表单填写。

表单初始带有旧的应用领域、型号、品牌、私模、包装方式和材质。测试确认这些字段被保存后的值替换；多选材质由 Wood 改为 Plastic 后，旧 Wood 选项取消。旧采集值仍只在来源快照中保留，不回填到发布数据。新增的必填应用领域、下拉季节和多选功能也成功填写。

该验证使用受控发布表单，不是在客户店铺直接提交商品，也不代表所有国际站类目控件已逐一实测。

## 图片水印

- 入口：批量修改 → 产品图片 → 本软件水印 → 水印类型“图片水印”。
- 上传客户自己的 JPG、PNG、WebP，单张最多 5 MB，透明 PNG/WebP 保留透明背景。
- 支持仅主图、仅详情图、主图和详情图，五种位置、宽度比例和透明度；保持图片宽高比，限制过高水印。
- 上传素材不会加入商品图片列表。点击添加/更新后先预览，再保存图片修改。
- 更新水印始终从底图重新合成，文字与图片水印可互换，不重复叠加。重新打开后删除软件水印恢复原底图。
- 详情 HTML 中的图片地址同步更新；原始采集快照保持不变。
