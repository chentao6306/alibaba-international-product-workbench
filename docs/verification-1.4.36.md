# 1.4.36 商品编辑、引用与发布修复

日期：2026-09-19。分支：`codex/brand-readback-1.4.36`。

## 问题与修复

两款 S26 Ultra 商品直接发布及引用成功商品后，均报「已采集但发布页未接受：品牌名称」。本地失败记录中的品牌为 `Other`，诊断字段为属性 ID `2`、`controlType: text`、`values: []`。已有手机发布表单记录显示该字段为普通文本框。

1.4.35 将 Other 选择项与后续自定义文本合并时，误把普通文本框中的字面值 `Other` 也过滤掉了。表单已填写，读回结果却为空，随后被本地必填属性检查拦截。更换引用模板无法修复这个控件读回错误。

- 保留普通文本框实际填写的 Other、Others、其他、其它、自定义及大小写形式。
- 当下拉框选择 Other、后续文本框填写具体品牌时，保留具体品牌作为有效值。
- 搜索框中的临时查询文字不算已提交属性。
- 成功发布属性快照与发布前校验使用同一读取函数，避免引用时只记录 Other 选项而漏掉后续具体品牌。
- 空值和与商品资料不符的品牌仍然拒绝通过。没有关闭必填校验，也没有自动修改客户商品数据或重采来源页。

## 验证

新增 `test/brand-readback.test.js`。修复前两个测试均能复现 Other 变为空数组；修复后直接填写、引用成功商品、Other 加自定义文本、临时搜索文字、清空及错误品牌均按预期处理。

最终全量测试 328 项通过，前端构建通过。桌面安装包检查通过：版本正确、打包服务代码一致、浏览器存在、登录窗口可启动、授权前 API 正确拒绝访问，Electron 安全开关保持启用。

真实账号检查：首个账号的 5G 手机发布页明确提示该类目不在经营范围内，尚未保存或提交。用户随后提供另一个账号，已登录并完成两款原失败手机的真实草稿保存，均收到国际站保存成功回执，刷新后品牌仍为 Other。首次遇到延迟出现的 AI 详描体验遮罩，已增加填写属性过程中对遮罩的检查和关闭。不会自动接受未知确认提示。

两款当前保存资料曾完整引用另一款手机，标题仍是 S26，但型号、系统及部分规格为被引用商品的值。已向用户询问正式发布采用原始采集资料还是引用后的资料，答复前未正式提交上架。草稿成功仅证明编辑、填写与保存通过，不能宣称两件商品已正式上架。

## 编辑窗口

采集商品单条编辑改为完整窗口，提供基础信息、商品属性、自定义属性、产品规格、交易信息、物流信息、商品服务与证书、商品描述、国家/地区差异设置九个页签。使用参考截图的蓝色标题栏、矩形页签、表单和固定底部按钮布局。

- 品牌选项与自定义品牌文字分别显示；保留多值属性和原始采集快照。
- 图片支持本地上传、地址添加、排序、删除与恢复来源；主图和详情视频分别编辑，支持本地 MP4。
- 规格组选项和规格图可编辑，重建组合时保留准确匹配 SKU 的价格、库存、编码与启用状态。
- 数量阶梯价、SKU 价、FOB 价格和多档交期分开编辑；物流、服务、证书、详情与地区价格有对应表单。
- 引用先应用到当前未保存的编辑内容，最终保存时与引用记录一并写入；放弃编辑不会偷偷修改商品。商品或模板发生并发修改时要求重新预览。
- 更换类目清除旧属性 ID，修改属性值清除旧选项 ID；防止旧映射覆盖新文字。

浏览器验收覆盖 1500px 桌面和 430px 窄窗口全部九个页签，无横向溢出；验证引用、保存、放弃、原商业资料保留和失败记录恢复。新增本地媒体接口及编辑 API 回归测试通过。商品分组、产地和发布进度原有浏览器验收通过。

本次编辑页的服务、证书、地区价格、箱规和详情视频支持保存资料；这些字段在不同类目发布表单上的完整自动映射尚未逐项完成真实验收，不应将编辑页验收等同于全部国际站字段已发布验证。图片银行、白底处理和结构化公司介绍图集等对方扩展工具未包含在本次实现中。

用户补充的 GWRC 螺旋桨截图是引用前基线：类目 `201346401`；品牌 Other + GWRC；适用品牌 Other + For FPV；产地 China / Guangdong；材质 Plastic；私模 No；颜色 Black（带规格图）；适用型号 10-Inch 1050；型号为空；类型 Propellers；自定义属性为空。

交易基线：Piece，2 件起 USD 3.5、500 件起 USD 2.9、2000 件起 USD 2.7；500 件以内 7 天。包装页显示 0.010 kg、7 × 7 × 3.5 cm。视频为空。以上是截图中的原始值，不代表已核验的商品事实。

引用后截图确认：类目 ID 仍为 `201346401`，路径改为中文；品牌变为 Other + PUSD；适用品牌变为 DJI、Others；材质变为 Metal、Rubber；私模变为 Yes；颜色和颜色规格图清空；适用型号变为 Other；型号变为 5.8G 3W 并带模板图；类型变为 FPV VTX。SKU 组合重建为适用型号、型号、类型。标题、5 张主图、交易、包装、服务及可对照的详情内容未变化。双方自定义属性均为空，不能据此判断其非空时的覆盖行为。

据此增加同类目完整引用回归用例，验证已有属性也覆盖、旧颜色清空、规格图跟随模板、原始采集快照及商业资料保留。发现旧兼容图片映射把「型号」图片也挂到「适用型号」组，已改为按准确字段别名及当前选项绑定，防止串组。

完整引用会覆盖实际产品属性；上述复制结果体现对方操作机制，不代表模板值一定适用于目标商品。系统保留预览和分范围引用能力。
