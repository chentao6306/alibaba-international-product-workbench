## 修复

- 历史快照指纹兼容：旧快照未变时不再误报。对现有 418 件商品只读核查，旧算法 417 件不匹配，修复后全部核对通过。没有改写来源快照和已有指纹；真正改动快照仍会被识别，新格式覆盖整个原始快照。
- 多选控件等待实际提交，按每个来源选项回读。修复固定 180ms 等待过短、部分选项丢失仍当作完成、原生多选不能接收旧格式逗号串的问题。
- 精确选项 ID 对应的翻译值可以跨填写阶段核对，避免把已选中文值误判成未填写而重复点击。
- 提交前重新核对类目属性，发现重绘丢值后补填。失败诊断保留属性 ID、控件类型和实际值。
- 暂停任务可以切换剩余商品的销售方式，保留成功商品、进度、库存策略、目标分组。说明询盘展示也会正式发布商品。
- 最小化/全屏发布窗口先恢复再最大化，修正隐藏窗口位置参数，关闭 CDP 会话的异常路径资源泄漏。

完整审查及竞品资料来源见 [发布稳定性审查](publishing-reliability-review.md)。
