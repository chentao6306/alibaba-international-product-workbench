# 1.4.62 分组采集、静音与属性规格修复

日期：2026-10-06。

## 行为

- 中国制造网默认进入店铺分组采集：读取店铺与父子分组、勾选批量采集、页码范围、每组数量上限、暂停继续。全部页不再在 100 页截断。保留单件/多链接采集、国际站类目匹配及成功商品引用。
- 分组任务关联商品，详情采集逐件保存断点；已通过链接采集的商品补充店铺关联，不覆盖已有人工编辑。
- Electron 所有网页内容创建时静音，导航时再次保持静音；所有生产 Chromium 启动路径附加静音参数，包括验证码与弹出窗口。不修改其他应用的音量。
- 根据启用 SKU 的实际价格或明确的规格定价模式选择按规格定价，按完整组合和虚拟表格行号填写各行价格、编码、库存及启用状态。提交前再次回读价格，不把不同价格退化为统一价格；缺少价格或组合不匹配时保留明确错误。
- 国际站详情模块新增读取 `attribute` 字段及产品属性列表，保存属性 ID。平台属性与同名自定义属性分开；例如平台电池容量区间与商家的单电池容量不可互换。中文标签通过属性 ID、页面观察到的双语标签及别名匹配，不依赖将买家页面切换成中文。
- 编辑器优先显示对应中文标签，保留来源键和值。旧商品已有英文值能重新对应；旧版漏存 ID 或合并了同名值的商品需要主动重新采集该件，核对手工修改，无须删除整个商品库。
- 可选图片守护协议优先选择“暂不接受”，不自动接受协议。组合修复将主图放在其他字段修复之后，并在最终提交前检查上传完成的远程图片记录。
