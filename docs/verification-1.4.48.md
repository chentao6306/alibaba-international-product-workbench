# 1.4.48 产地控件恢复与授权码重置

- `server/publisher.js`：产地字段最多尝试三次，每次重新查找控件，等待异步选项和实际选中值；仅恢复控件超时或替换。未完成时记录字段、步骤、次数及控件状态，避免展示无定位信息的通用提示。

- `auth-server/security.js`、`index.js`、`dev.js`：授权码重置支持显式保留已验证会话；不改变签名、心跳版本检查、单设备限制或授权有效期。
- `auth-server/admin.js`、`admin.html`：新增“同时退出已登录设备”，多端账号默认不勾选；显示本次重置对设备的实际影响。
- 授权测试、管理页面验证工具与说明同步更新。

本轮没有改变商品采集数据、任务队列、型号/价格/库存、引用范围或风险提示发布策略。客户端包仍包含 1.4.47 的跨类目属性冲突修复。

## 副作用与未解决问题

产地重试局限于单字段，不刷新表单、不重复保存/提交；已有字段值和省份不会被重试更改。无法确认选中值时不报告成功；暂停、页面关闭和平台风险错误保持原处理。阿里巴巴后续改版仍可能需要适配。

授权服务使用原有事务及行锁串行处理登录、重置和心跳；不回退会话版本，因此之前撤销的 token 不会恢复。停用、注销、删除、到期和单设备互踢继续生效。

另一个用户反馈仍待复现：1.4.47 在毛绒背包上提示“请确认禁限售规则”。代码目前处理风险警告弹窗，未覆盖该独立规则确认形态。本安装包不声称修复此问题，需相同商品链接/ID及实际页面控件证据。

## 手动验证

1. 退出旧客户端，安装 1.4.48，检查原商品和任务仍存在。
2. 对 G630 暂停任务点击继续，或选择原失败商品重新执行；无需删除或重新采集。先保存草稿，核对标题、产地及其他字段。
3. 刷新授权管理页面，确认账号允许多端；A 电脑保持登录，重置授权码时不勾选“同时退出已登录设备”。
4. B 电脑使用新码登录，等待至少一个心跳周期（约 30 秒）；A、B 应均保持有效。
5. 需要撤销原设备时，明确勾选该选项后重置；原设备应在下次授权检查时要求重新登录。
