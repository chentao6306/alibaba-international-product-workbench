# 1.4.101 候选版记录

日期：2026-11-09。源码分支 `codex/1.4.101`。继承 [1.4.100](release-1.4.100.md)，包含完整客户端、本地服务、授权后台、官网及构建源码；后台业务代码本次没有变化。客户资料和验收回执保留在私有目录。

## 连续发布页面隔离

客户 1.4.99 诊断确认：上一商品出现保存成功提示后，平台延迟跳转到该商品的草稿编辑页；下一商品已开始打开目标类目，复用的页面导航被前一次跳转打断，随后被概括成“国际站页面操作未完成”。

每次新商品发布现在创建独立页面，复用经过核验的浏览器会话，清理上一自动化页面。单件失败的页面保留到诊断完成和下一次开始时，其他用户打开的页面不清理。操作结束释放该商品暂停监听，避免旧监听影响后续商品。

仅在尚未填写或提交的新页面导航阶段，有界重试导航中断。首次写入前检查是否误入带有已有商品编号的编辑页，防止按目标类目 URL 回退判断而覆盖上一商品。保存或提交后的未知回执仍不重发操作。

## 保存回执新鲜性

相邻流程检查复现了另一个问题：前一次“保存成功”仍在页面时，后一次保存没有新回执也可能被记为成功。现在在真实点击之前记录页面提示基线，只接受这次动作后新建、改写或重新显示的成功提示，以及新的成功 URL。旧提示的附加时间文字变化、URL 仅改变锚点均不算新结果；同一文本节点经过“保存中”恢复成功、同一 URL 导航到新文档并显示成功也能正确识别。没有新回执时保留“结果待核对”，不补点保存或提交。已明确拒绝后允许的修复、平台质量确认等流程仍按当次动作重建基线。

## SKU 身份与语言转换

- 保留 1.4.100 的同名选项 ID 恢复：40 个客户 SKU 分别保留图片、价格、库存和编码。
- `Model` 和 `Model Number` 等分别存在的来源维度，精确名称优先；仅在唯一时使用别名，避免规格合并或交叉匹配图片和价格。
- 规格图优先使用来源图片维度时，按 ID 或精确名称查找目标，避免别名再次选回当前文字维度而循环；目标 ID 重映射、自身匹配及不相关文字维度都有浏览器回归。
- 选项名在英文转换后碰撞时，按明确来源 ID 增加区分编号；保留原始名称、用户资料和全部 SKU，不通过删除组合处理冲突。
- 维度重名和选项重名同时出现时，可以使用新采集保留的逐项 ID 恢复；旧数据缺少充分证据时继续明确停止，不能按位置猜测。

## 已发布商品的视频关联

视频选择器已经展示唯一且编号正确的目标商品时，直接按该商品卡片和数字复选框关联，不再先执行可选的高级搜索。目标不可见时仍按精确商品编号搜索；勾选其他商品、目标不唯一或无法找到时停止，不能使用首项代替。提交关联后仍独立读取关联列表，核对商品编号和主图/详情角色。

本轮针对此前已发布的消费电子手机，使用原有两段已审核视频完成主图、详情关联，平台列表对两种角色的核对均通过，没有重新上传视频或重复发布商品。原重试只有外层 90 秒超时，无法据此认定具体哪个控件超时；只读检查时高级搜索输入实际可见。此次修复去除不必要的搜索依赖，不能把此前等待都归因于隐藏输入框。

随后商品公开页及编辑页只读回查通过：主图视频的编号出现在平台页面数据中，详情原生视频模块保留另一编号。公开页观察到的两个视频地址均完整解码播放到结束，分别约 41.87 秒（1270×720）和 26.40 秒（720×720），无解码错误。两种详情播放域名属于同一视频编号，现有 `videoResourceKey` 会在上传计划中去重。该结果补齐这件手机的双视频关联与播放验收，不代表所有类目或所有视频时长都得到平台许可。
