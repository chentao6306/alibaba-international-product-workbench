# 1.4.39 发布后台运行与物流默认设置

## 行为

- 发布使用无原生窗口的 Chromium 会话，保留 1280×900 页面尺寸；页面重建、登录失效和发布安全验证均不会自动打开发布窗口或任务栏图标。用户主动打开卖家窗口的入口保留。
- 主图上传入口在滚动、动画、延迟提示或重新渲染后会重新定位并有限重试，已上传的图片及顺序保留。
- 浏览器技术异常和阶段长时间无进展保留为暂停状态，不计入商品失败，不把调用日志展示给用户。
- 空白运费模板默认使用“买卖双方协商物流”，空白箱规默认使用“一箱多件”。编辑页保存与发布填写使用相同默认规则；已有明确设置保留。发布时仅匹配可用的对应选项。
- 重量、尺寸和物流属性使用商品资料，不补造统一的重量或普货属性。自动判断仍依据页面的商机品状态和实际必填条件选择销售方式。
- 普通的交易品物流条件清单不作为提交拒绝原因；相同内容如果位于国际站明确的错误区域则继续展示。无成功回执且无明确拒绝时暂停待核对，不自动重复提交。
- 包含 1.4.38 的质量分“继续提交”处理；只有明确成功回执才记为成功。
