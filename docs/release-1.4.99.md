# 1.4.99 候选版记录

日期：2026-11-09。源码分支 `codex/1.4.99`。继承 1.4.98 的客户端、本地业务服务、授权后台、官网及开发工具，不包含商品库、用户库、客户日志、会话或密钥。

## 用户可见变化

- 空闲时自动读取进度不再同步阻塞本地服务等待桌面状态；桌面暂时不响应时有界返回，后续轮询能够恢复。每次写入仍必须通过当次授权。
- 进度查询失败后的桌面诊断也有等待上限，不会一直占用后续刷新。侧栏明确区分桌面连接超时、后台停止、授权和存储等情况。
- 大批引用商品资料按商品分段计算并异步落盘，预览、保存期间仍可读取状态。全部选择保留在预览令牌内；并发修改、任务变化或写盘失败不会用旧数据覆盖新状态。
- 为已确认的超长服务属性名称提供等义英文名称，保留来源名和值；未知长名称不盲目截断。
- 优先保留来源详情格式。目标账号没有新版入口时，可兼容普通图文编辑器；转换保留当前正文、表格、FAQ、图集标题及图片顺序，并在上传后和提交前核对表单实际值。原始快照不变，视频仍走独立上传和关联流程，结果明确记录转换原因。
- 详情图片恢复原文位置后补齐编辑完成事件，避免画面已更新、提交模型却仍是“正文后追加全部图片”的旧顺序。
- 发布页隐藏内嵌主图视频控件、但提供视频素材库入口时，继续验证和使用该入口；不再直接误报视频功能未开放。没有任何可用入口时仍明确停止。
- 上传副本先将透明图片按商品页白底合成并应用图片方向，避免平台转 JPEG 后出现黑色背景；刷新上传缓存，原始采集和编辑图片不变。

本版没有关闭属性、SKU、图片、视频、草稿和提交结果的核验，没有通过少传来源资料来提高表面成功率。规则模式仍独立可用。
